# 🏠 NYC House Type Predictor

A Streamlit web app that predicts **house type categories in New York City** based on property features such as borough, building class, land square footage, gross square footage, and year built.  
This project is built from the Kaggle NYC Housing dataset and uses a trained machine learning pipeline.

---

## 🚀 Features
- Interactive UI built with **Streamlit**
- User-friendly input fields for property details
- Real-time prediction of house type
- Supports both single property input and dataset upload (optional extension)

---

## 📂 Project Structure
- `app.py` → Streamlit application code
- `Model_Pipeline.pkl` → Trained ML pipeline (saved with Joblib)
- `README.md` → Project documentation
- 'Requirements.txt' -> required libraries for the model
